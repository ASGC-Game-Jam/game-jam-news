Day 0: The Jam Starts With the Leads

Weekly Digest · Jun 07 – Jun 14, 2026 · 16 messages from 2 members

Welcome back to the Weekly Digest! It was a quiet week in message count but a big one for planning. On Friday, June 12, Xelnath laid the groundwork for the upcoming game jam: a Day 0 checklist for discipline leads and a clear framework for deciding how AI and LLM tools can be used. The next moves belong to the leads.

The Community Poll That Will Seed the Jam

In #Day-0-Tasks for Leads, Xelnath asked each discipline to propose 5 options for a community poll that Amir will run. The top results become the jam's starting brief:

  • Narrative → Theme
  • Design → Genre
  • Art → Style
  • Programming → Main Character Animal Species 🐾
  • Production → 1 special limitation

Other disciplines can pitch in too. Leads, now is the time to start shortlisting!

Leads' Day 0 Checklist

Beyond the poll, Xelnath's seven-item list asks each lead to sort out how their team will run:

  • Internal collaboration: how decisions get made, how assets are committed, how people notify each other, and how rework and feedback are handled
  • GitHub workflow: adding people, working on the project, and merging
  • Documentation: Xelnath recommends a master Google Doc index that links to short 1–2 page detail docs
  • Onboarding: instructions, a video or a doc for your discipline
  • Logistics: request the roles, powers and channels you need
  • Homework: watch the leads onboarding video

AI & LLM Rules: Each Discipline Decides for Itself

Over in #Day-1-LLM Based Generation & Tools, Xelnath explained how AI use will be governed during the event. The mods won't make the call. Instead, each discipline decides for itself, but not for the others. For example:

  • If Art doesn't want it, it's banned for art.
  • If Programming allows it for tools, it's permitted.
  • QA can choose whether to automate with it.

He recommended that every discipline discuss three categories separately:

  1. Content generation
  2. Tool generation
  3. Debugging / refinement

⏰ Deadline: end of Day 2, so the rules can be shared with participants.
