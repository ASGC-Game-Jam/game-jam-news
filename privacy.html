Atomech Observer privacy policy

Effective 9 November 2026.

Atomech Observer is a Discord bot that writes a weekly newsletter for the Funsmith Club and ASGC Game Jam Discord servers. This page explains what it collects, why, and how long it keeps it.

What the bot collects

From channels the bot has been given access to, for the period being summarized, the bot stores each message's text, author ID, author name (the server nickname on Funsmith Club), channel, time, reply link, reaction count, link previews, and attachment names and links. It skips join, pin and boost notices and messages from bots. Channels that server admins exclude, such as ModMail, are never read.

The bot does not collect presence or activity, direct messages, voice, email addresses or payment information.

How it is used

Messages are used only to write channel summaries, a server report and the weekly newsletter. The newsletter can include short quotes, member names and images that were posted in the server. It is posted back to a channel in the same server. The ASGC Game Jam newsletter is also published on a public website.

The data is not sold, used for advertising, or shared with anyone except as described here.

Who processes it

To write summaries, the week's message text and author names are sent to Anthropic's Claude API. Under Anthropic's commercial terms, API data is not used to train their models by default. Some summaries are written by a model running locally on the operator's computer instead, and that data does not leave it.

Where it is stored

Stored messages are kept in a database on the operator's own computer, not on a hosted server, and only the operator has access to it. The bot's credentials are kept in local configuration files.

How long it is kept

Stored messages are deleted once they are 90 days old, after the operator confirms each deletion. Finished newsletters and reports are kept as an archive.

Your choices

You can ask for all of your stored messages to be deleted, or to be left out of future newsletters, by contacting support@gamedesignskills.com. Server admins can also keep the bot out of any channel by removing its access.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.

Questions: support@gamedesignskills.com.
